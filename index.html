THE PROCESS

From Voice to Visible Results.

VOCULUS brings together voice recognition, mathematical processing and physical movement to create a new way of interacting with calculations.

01 / INPUT
🎙️

Speak

A user speaks a simple mathematical expression into a microphone. Python speech recognition processes the spoken input.

02 / PROCESSING
⚙️

Calculate

Python interprets the expression, performs the arithmetic operation and communicates the result to the Arduino Mega.

03 / OUTPUT
🔢

Display

The Arduino controls servo motors that position the segments to display the numerical result physically.

WHAT MAKES IT DIFFERENT

A Calculator, Reimagined.

VOCULUS combines familiar arithmetic with an alternative, voice-based interface and a mechanical display.

🎤

Voice-Based Input

Mathematical expressions can be spoken instead of entered using a traditional keypad.

🔩

Mechanical Display

Servo motors physically position the seven-segment display elements to represent numbers.

💻

Python Processing

Speech recognition and arithmetic processing work together to interpret spoken expressions.

🔌

Arduino Integration

Serial communication connects the calculation software to the Arduino Mega and its servo motors.
