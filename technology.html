🐍 SOFTWARE · PYTHON
SOFTWARE ENGINEERING

Python: The Thinking Layer.

Python acts as the software foundation of VOCULUS. It processes the recognised speech, performs the required calculation and communicates the result to the Arduino.

  • Speech recognition through a Python library.
  • Interpretation of mathematical expressions.
  • Arithmetic processing.
  • Serial communication with the Arduino.
🧠 HARDWARE · ARDUINO MEGA
EMBEDDED SYSTEMS

Arduino Mega: The Controller.

The Arduino Mega acts as the hardware control unit. It receives the result from Python and sends the required control signals to the servo motors.

  • Receives data through serial communication.
  • Maps numerical values to display patterns.
  • Controls 14 servo motor positions.
  • Coordinates the two-digit display.
14 SERVO MOTORS · 7 PER DIGIT
MECHANICAL ENGINEERING

Servo Motors: Movement With Purpose.

VOCULUS uses 14 servo motors, with seven dedicated to each digit. Each motor positions a corresponding segment of the display.

  • Seven controlled segments for each digit.
  • Individual servo positioning.
  • Two-digit numerical output.
  • Arduino-controlled mechanical movement.
ILLUSTRATIVE SEGMENT PATTERN
VISUAL OUTPUT

Seven Segments. Endless Possibilities.

The physical display uses seven individual segments for each digit. By positioning these segments in different combinations, the system represents numerical values.

  • Two separate digit positions.
  • Seven segments in each digit.
  • Fourteen servo-operated segments in total.
  • A physical display rather than a conventional electronic screen.
THE BIG PICTURE
