From Spoken Words
to Physical Numbers.

VOCULUS connects voice recognition, mathematical processing and mechanical movement in one integrated system. Here's how every stage works together.

🎙️
AUDIO INPUT CAPTURE
01 / VOICE INPUT

It Starts With Your Voice.

The user speaks a mathematical expression into a microphone. Python's speech-recognition system processes the audio and converts the spoken words into text that the program can interpret.

  • Captures spoken mathematical expressions.
  • Recognises words such as plus, minus and multiplied by.
  • Passes the recognised expression to the calculation program.
VOCULUS · PYTHON PROCESSING
INPUT:
"Twenty-five plus seventeen"

INTERPRETATION:
25 + 17

CALCULATION:
25 + 17 = 42

RESULT READY ✓
SOFTWARE PROCESSING
02 / PYTHON PROCESSING

Words Become Calculations.

Python interprets the recognised expression, identifies the numbers and arithmetic operation, and calculates the answer. The program then prepares the result for the Arduino.

  • Processes the recognised text.
  • Identifies the mathematical operation.
  • Calculates the numerical answer.
  • Prepares the result for serial transmission.
ARDUINO MEGA CONTROL UNIT
SERIAL COMMUNICATION
03 / ARDUINO CONTROL

The Result Reaches the Hardware.

The Python program sends the calculated result to the Arduino Mega using serial communication. The Arduino reads the received value and determines the servo positions needed for the display.

  • Receives the result from the computer.
  • Interprets the numerical value.
  • Determines the required display pattern.
  • Controls the connected servo motors.
SERVO MOTOR MOVEMENT
04 / PHYSICAL DISPLAY

Movement Creates the Answer.

The Arduino sends control signals to the servo motors. These motors physically position the seven-segment elements to form the required digits on the two-digit display.

  • Servo motors receive their control signals.
  • Individual display segments move into position.
  • The two-digit display forms the calculated answer.
  • The result becomes visible without a traditional keypad.

What makes VOCULUS different?

Instead of relying on a conventional keypad and electronic screen, VOCULUS uses spoken input and a physical servo-operated display to demonstrate an alternative way of performing calculations.
