THE VOCULUS WORKING SEQUENCE

THE PROCESS EXPLAINED

Every stage matters.

Each component has a specific role in converting the spoken instruction into a displayed answer.

01

Voice Input

The user speaks a mathematical instruction into a microphone. This provides the input without requiring a conventional keypad.

02

Speech Recognition

Speech recognition software converts the spoken words into text that the computer can process.

03

Python Processing

Python interprets the recognized mathematical instruction, identifies the operation and calculates the result.

04

Serial Communication

The calculated result is sent from the computer to the Arduino through serial communication.

05

Arduino Control

The Arduino processes the received result and determines the required positions of the servo-operated segments.

06

Mechanical Display

Fourteen servo motors move the individual segments to form the two digits representing the final answer.

A PRACTICAL EXAMPLE

Let's calculate 25 + 17.

Here's an illustrative example of how an instruction moves through the VOCULUS system.

SPOKEN INSTRUCTION
25 + 17
CALCULATED RESULT
42

The recognized instruction is processed by Python. The result is transmitted to Arduino, which positions the servo-operated segments to display 42.

Technical note: The animated graphics and calculation example on this webpage are explanatory illustrations. They do not connect to the physical VOCULUS hardware or operate its microphone, Arduino or servo motors.
